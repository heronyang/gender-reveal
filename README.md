# 寶寶性別大猜謎

給遠方家人投票猜寶寶性別（男生／女生）並寫下理由的小網站。猜對的人可抽煙波大飯店溫泉住宿券。

- `index.html`：投票頁（分享這個連結給家人）
- `results.html`：主辦人看票數、理由、揭曉後抽獎
- `apps-script/Code.gs`：Google Apps Script 後端，票存在 Google 試算表
- `config.js`：填入 Apps Script 網址

## 設定後端（約 3 分鐘，只需一次）

1. 到 Google 試算表建立一個新試算表（例如命名為「寶寶性別投票」）。
2. 選單「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 的內容整個貼上，存檔。
3. 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」並授權（會出現「Google 尚未驗證這個應用程式」→ 進階 → 前往）。
5. 複製「網頁應用程式網址」（結尾是 `/exec`），貼到 `config.js` 的 `VOTE_API_URL`，commit 並 push。

之後修改 `Code.gs` 時，要用「部署 → 管理部署作業 → 編輯 → 新版本」，網址才會維持不變。

## 看結果

- 打開試算表的「投票」分頁，即時看到每一票。
- 或打開網站的 `results.html`，揭曉後選擇性別並按「開始抽獎」。
